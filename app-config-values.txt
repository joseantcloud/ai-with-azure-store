DESCRIPCIÓN
===========

Store_name
Nombre de la tienda.

Discount
Activa o desactiva el descuento del 20%.
Valores: true / false

Display_products_amount
Cantidad de productos visibles.
Ejemplos: 5, 10, 14, 25, 50, 100.

AI_enabled
Activa o desactiva Azure AI.
Valores: true / false

AI_Model
Deployment/modelo utilizado por Azure AI.

AI_Welcome_Prompt
Prompt usado para generar el mensaje de bienvenida.

AI_Recommendation_Enabled
Activa o desactiva la recomendación automática.
Valores: true / false

AI_Refresh_seconds
Intervalo de las recomendaciones de AI.
Este valor ES CONTROLADO por Azure App Configuration.

Ejemplo:
15

Luego cambiar a:
30

La siguiente respuesta de /api/recommendation devolverá:
refresh_seconds = 30


DIFERENCIA IMPORTANTE
=====================

AI_Refresh_seconds NO es el refresh del provider de
Azure App Configuration.

El provider usa internamente:

refresh_interval = 5

Ese valor controla cuándo puede comprobar cambios
de configuración.

AI_Refresh_seconds controla cuándo el navegador
solicita una nueva recomendación de AI.

============================================================
CREDENCIALES DE LA DEMO LOCAL
============================================================

APP CONFIGURATION
Azure Portal -> App Configuration -> Access keys
Copiar: Connection string
Pegar en app.py:
APP_CONFIG_CONNECTION_STRING = "..."

AZURE AI
Azure AI Foundry -> proyecto -> modelo/deployment ->
Use your model in code
Copiar: Endpoint y Key
Pegar en app.py:
AZURE_AI_ENDPOINT = "..."
AZURE_OPENAI_API_KEY = "..."

Para esta demo local se mantienen directamente en app.py para que el
ejemplo sea fácil de seguir. No usar este patrón para producción.
